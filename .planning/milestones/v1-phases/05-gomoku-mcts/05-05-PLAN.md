# Phase 5: Gomoku — MCTS + Policy/Value Network

## Phase 4 DQN의 한계

Phase 4에서 DQN으로 Connect Four를 학습했다. DQN은 신경망으로 Q값을 근사해 Q-table의 메모리 한계를 극복했다.
그러나 Gomoku(오목) 같은 복잡한 게임에서 DQN은 치명적인 약점이 있다.

- **탐색 부재**: DQN은 현재 상태에서 단 한 수 앞만 본다. 오목에서 5수 앞의 장기 위협을 인식하지 못한다.
- **희소 보상**: 오목은 게임 종료 시에만 보상이 발생한다. DQN의 Bellman equation은 종료까지 225수가 걸리는 게임에서 보상 신호를 효과적으로 전파하지 못한다.
- **전략 계획 불가**: 좋은 오목 전략은 "지금 당장 좋은 수"가 아니라 "미래 국면을 유리하게 만드는 수"다.

이를 해결하는 열쇠는 **트리 탐색(Tree Search)**이다.

## MCTS (Monte Carlo Tree Search)

MCTS는 실제 게임을 반복 시뮬레이션해 각 수의 가치를 추정한다.
4단계로 구성된다.

```
1. Selection   — PUCT 점수로 트리를 내려가 리프 노드 선택
2. Expansion   — 리프 노드를 신경망으로 평가하고 자식 노드 생성
3. Evaluation  — 신경망이 현재 국면의 가치(Value)를 예측
4. Backpropagate — 예측값을 트리 위로 전파 (관점 전환 포함)
```

### PUCT 탐색 공식

AlphaZero의 핵심 탐색 공식은 **PUCT (Polynomial Upper Confidence Trees)**다.

$$
\text{PUCT}(s, a) = Q(s, a) + c_\text{puct} \cdot P(s, a) \cdot \frac{\sqrt{N_\text{parent}}}{1 + N_\text{child}}
$$

- $Q(s,a)$: 지금까지 관찰된 평균 가치 (exploitation)
- $P(s,a)$: Policy Network가 예측한 사전 확률 (prior)
- $N_\text{parent}$: 부모 노드 방문 횟수
- $N_\text{child}$: 현재 자식 노드 방문 횟수
- $c_\text{puct} = 5.0$: 탐색 vs 활용 균형 상수

방문이 적은 자식(분모가 작음)은 $U$ 항이 커져 자연스럽게 탐색된다.
충분히 방문한 자식은 $Q$ 항이 지배해 활용(exploitation)으로 수렴한다.

### Backpropagation의 관점 전환

두 플레이어 제로섬 게임에서 가치는 항상 "방금 수를 둔 플레이어"의 관점으로 저장된다.
리프 노드 가치 $v$를 부모로 전파할 때 부호를 뒤집는다.

```
leaf.UpdateRecursive(-leafValue)
  → leaf.Update(-1.0)       // leaf: TotalValue = -1.0
  → parent.Update(+1.0)    // parent: negated once
  → grandparent.Update(-1.0) // grandparent: negated twice
```

## Policy/Value Network 설계

신경망은 두 가지 출력을 가진 **듀얼 헤드(dual-head)** 구조다.

### 입력: 4채널 보드 인코딩

| 채널 | 내용 |
|------|------|
| 0 | 현재 플레이어의 돌 (1.0) |
| 1 | 상대 플레이어의 돌 (1.0) |
| 2 | 마지막 수 위치 (1.0) |
| 3 | 턴 표시 (Black이면 전체 1.0, White면 0.0) |

### 네트워크 구조

```
[4, 15, 15] 입력
→ Conv2d(4→32, 3×3) + BatchNorm + ReLU
→ Conv2d(32→64, 3×3) + BatchNorm + ReLU
→ Conv2d(64→128, 3×3) + BatchNorm + ReLU
                    ┌─────────────────────────────────────┐
    Policy Head     │  Conv2d(128→4, 1×1) + BN + ReLU     │
                    │  Flatten → Linear(900→225)           │
                    │  log_softmax → [225] log-확률        │
                    └─────────────────────────────────────┘
                    ┌─────────────────────────────────────┐
    Value Head      │  Conv2d(128→2, 1×1) + BN + ReLU     │
                    │  Flatten → Linear(450→256) → Linear(256→1) │
                    │  tanh → [-1, 1] 스칼라              │
                    └─────────────────────────────────────┘
```

## 자가 대국 학습 파이프라인

AlphaZero 스타일 학습은 세 단계가 순환한다.

```
[자가 대국] → [데이터 수집] → [신경망 학습] → [자가 대국] → ...
```

### 훈련 데이터 형식

```fsharp
type TrainingSample = {
    State:        float32[]  // 보드 인코딩 [4×15×15 = 900]
    PolicyTarget: float32[]  // MCTS 방문 분포 [225] (합 = 1)
    ValueTarget:  float32    // +1 = 이 플레이어가 이김, -1 = 짐, 0 = 무승부
}
```

### 손실 함수

$$
\mathcal{L} = -\sum_i \pi_i \log p_i + \text{MSE}(z, v)
$$

- $\pi$: MCTS 방문 분포 (정책 타겟)
- $p$: Policy Head 출력 (log-softmax)
- $z$: 게임 결과 (+1/-1/0)
- $v$: Value Head 출력

## Tutorial 전체 정리

이 시리즈에서 우리는 RL의 핵심 개념들을 단계별로 구현했다.

| Phase | 개념 | 핵심 알고리즘 |
|-------|------|--------------|
| 1. Bandit | Exploration vs Exploitation | ε-greedy, UCB1 |
| 2. TicTacToe | MDP, Value Function | TD(0) |
| 3. Connect Four | Q-Learning, Tree Search | Minimax + Alpha-Beta |
| 4. DQN | Neural Q-Learning | Experience Replay, Target Network |
| 5. Gomoku | MCTS + Neural Network | PUCT, Self-Play, Policy/Value Net |

각 Phase는 이전 Phase의 한계를 극복하는 새로운 아이디어를 도입했다.
Bandit(상태 없음) → TD Learning(작은 상태 공간) → Minimax(완전 탐색) → DQN(신경망 근사) → AlphaZero(탐색 + 신경망).

이것이 현대 RL의 발전 경로다.
