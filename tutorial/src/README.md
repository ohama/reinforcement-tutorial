# F#으로 배우는 강화학습

이 튜토리얼은 F#으로 강화학습(Reinforcement Learning) 핵심 알고리즘을 단계별로 구현하며 배우는 실전 가이드입니다.

## 구성

| Chapter | 게임 | 핵심 개념 |
|---------|------|----------|
| 1 | 슬롯머신 (Bandit) | Exploration vs Exploitation, ε-greedy, UCB1 |
| 2 | 틱택토 | MDP, Value Function, TD Learning |
| 3 | 커넥트 포 | Q-Learning, Minimax, Alpha-Beta Pruning |
| 4 | 커넥트 포 DQN | 신경망, Experience Replay, Target Network |
| 5 | 오목 | MCTS, Policy/Value Network, Self-Play |

## 전제 조건

- F# 기본 문법 숙지
- .NET 9 SDK 설치
- RL 개념 사전 지식 불필요 — 이 튜토리얼에서 다룸
